Flash Your CYD PhotoFrame Firmware to 4.2!

A guide to flashing ESP32 firmware for the CYD PhotoFrame. This ESP32 project features a slideshow viewer and built-in WiFi setup, perfect for showcasing your images using the Cheap Yellow Display (CYD) board.

Code for this project: GitHub Repository.

After uploading the firmware, the LCD screen should guide you through WiFi setup. For full setup instructions, visit the Wiki Setup Page.

If you do not see the COM port, you may need to install the CH340 drivers. See the instructions below.

Click one of the buttons below to flash the latest firmware (version 4.2) to your ESP32 device.

Which button? It depends on the display panel in your board, not on the number of USB ports. If you pick the wrong one the screen stays white or the picture looks like a negative — nothing is damaged, just flash another button. Start with the first one (button 4 is only for the 3.5-inch CYD). If photo colours look wrong (reds are blue) but nothing else, you don’t need another file: open the frame’s web page, go to Settings and tick Swap red and blue.

Note: installing from this page replaces everything on the board, including a saved WiFi login and settings, so the frame will ask you to set up WiFi again. Photos on the SD card are not touched. To keep your settings when updating a frame that already runs 4.0, use the Firmware update button on its own web page (http://photoframe.local/update) with an update.bin file from the latest release.

1. CYD — ILI9341 display, normal colours

The standard CYD with one USB port, and many boards with two USB ports. Try this one first.

2. CYD2 — ST7789 display

Boards with two USB ports and an ST7789 display. Choose this if button 1 gives a white screen.

3. CYD2 alternate — ILI9341 display, inverted colours

Choose this if button 1 shows a negative picture (colours inverted).

4. 3.5-inch CYD — ST7796 display, 480×320

Only for the 3.5-inch CYD (for example the ESP32-32E / ESP32-3248S035 board). On the first start the frame asks you to touch the four corners of the screen to calibrate touch. Confirmed working by a user; sound has not been tested on this board yet.

Already have a frame running this firmware on your WiFi? You can instead download CYD-PhotoFrame-cyd35-update.bin and upload it at http://photoframe.local/update; that keeps your WiFi login. If the colours look wrong, open the frame’s web page, go to Settings and try Swap red and blue and/or Invert colours.

Do You Need CH340 Drivers?

If your computer is unable to recognize the ESP32 when you try to flash the firmware, you may need to install the CH340 USB-to-serial drivers.

How to Install the CH340 Driver:

  • Download the CH340 driver for your operating system:
    • Windows Driver (CH340)
    • Mac OS Driver (CH340)
  • Unzip the downloaded file.
  • Run the installer and follow the on-screen instructions to complete the installation.
  • Once installed, reconnect your ESP32 and try flashing the firmware again.

After installing the drivers, your computer should recognize the ESP32, and you can proceed with flashing the firmware.
